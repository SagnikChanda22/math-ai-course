Measure theory visualizations and examples

Files:
- visualize_measures.py: Python script sampling and plotting examples for different measures (atomic, continuous, singular).
- requirements.txt: Python package list (numpy, matplotlib).

Run:

```bash
python -m pip install -r requirements.txt
python visualize_measures.py
```

Notes:
- The Cantor sampler approximates the Cantor distribution by truncating the infinite series.
- If Python is not available in your environment, you can convert the script to a Jupyter notebook or run it in any environment with Python 3 and the listed packages.
